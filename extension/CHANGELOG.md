# Changelog

## 1.0.0

首个公开发布版本。

- **右侧栏面板**：把桌面版 DeepSeek Harness 的会话、模型、历史接入 VS Code 辅助侧边栏，同一份会话实时同步。
- **选区一键入框**：`Ctrl+Alt+A` 把选中代码按「路径 + 行号 + 代码块」带入对话框；面板内也有「引用选区」按钮。
- **流式输出**：思考过程可折叠，正文逐字出现，每条回复标注 token 用量（`↑输入 ↓输出`）。
- **结构化工具卡片**：`read` 显示带行号的文件片段，`edit` 显示红绿 diff，`bash`/`pwsh` 显示命令与输出。
- **图片附件**：输入框内粘贴或拖入图片随消息发送；重新打开历史会话时自动回填缩略图。
- **会话操作**：右上角「⋯」重命名 / 创建分支；模型选择器支持置顶与最近使用。
- **开箱即用**：扩展内置桥接插件，可用「安装桥接插件到桌面版」一键写入桌面版 profile。
- **设置热生效**：修改 `dsh.home` / `dsh.bridgeFile` 立即重连，无需重载窗口。
